# Plan: the wand tab's bugs found while rewriting the user guide

**Date:** 2026-10-07. **Asked:** "please go on and fix those bugs. for the Precalibration, i think we should just
remove that or show the results from the start stage?" (after the guide's inventory listed them).
**Status:** approved by that message; the flat-window precheck shows the start stage's results (the second option:
it does what the tube model's precheck does, and keeps a check for that model).

## The fixes

| # | bug | fix | where |
|---|---|---|---|
| B1 | Wand Type "Bright on Dark" behaves as "Dark on Bright": `"dark" if "Dark" in text`, and both texts contain "Dark" | one helper, `_wand_type()`: "bright" when the text starts with "Bright", used at the three places | view.py |
| B2 | The flat-window result says "Tick 'Use the previous calibrator' to align the world to axis points"; that calibrator skips the alignment every time (`_refr_cams_cpp` is never set) | the note says axis points are not applied (as the tube's does); the previous calibrator says so in its result box instead of only on the console | view.py |
| B3 | "Precalibrate to Check" with Pinhole+Refraction runs the plain pinhole check, without the windows | with plate_wand: its start search and coarse fit (stages 1-3), in the separate process like the run, then the error table, the 3D View and a "Check Complete" box, no files (as the tube's precheck). `plate_wand.calibrate`'s nested `make_starts` becomes the module-level `start_candidates` (a pure move) so that the GUI can call it; new `plate_wand_gui.precheck`, `child_precheck`, `precheck_lines`. With "Use the previous calibrator" ticked the pinhole check stays (that calibrator's workflow) | plate_wand.py, plate_wand_gui.py, view.py |
| B4 | Deleted frames cannot be restored in a session; the marks also apply to points loaded later; a filter change overwrites manual Del marks | the deletions are cleared when new points are loaded or detected; a "Restore Deleted Frames" button; a Del box clicked by hand keeps its state when a filter re-marks the rows | view.py |
| B5 | Pause in the detection dialog does not pause the worker processes (every task is submitted at the start) | tasks are submitted as results come back, at most 2 per worker in flight: when the GUI stops reading (Pause), no new task starts | wand_calibrator.py |
| B6 | Changing Num Cameras clears every camera's folder, Focal, Width, Height and window | the cameras that remain keep them (also when the number of windows changes, while their window exists) | view.py |
| B7 | The Refraction panel's indices take two decimals (water 1.33) | four decimals; Water 1.333, as the Tube panel | view.py |
| B8 | The Tube and Refraction panels are wider than the control column | narrower index fields in the side-by-side rows (`_apply_input_style` gets an optional width), shorter check-box texts with the details in their tooltips | view.py |
| B9 | Pinhole camFiles carry the first camera's image size | each camera's own size (already in `final_params[c]['img_size']`) | wand_calibrator.py |
| B10 | Pinhole: clicking an error-table row shows no reprojection crosses | `calculate_per_frame_errors` keeps the projections it computes (`proj_pts`), as the other models' tables do | wand_calibrator.py |

Not changed: the calibrations' results (B3's move must leave plate_wand's answers identical), axis alignment for the
tube and flat-window models (a feature: not applied, as documented), the previous refraction calibrator's own code.
