## What the code does now (read for this plan)

- **The Pinhole calibration** (`WandCalibrator.calibrate_wand`, the second of its two definitions) runs in three
  phases:
  - **Phase 1:** the best camera pair, with the 4-stage `_run_optimization_pipeline`;
  - **Phase 2:** the other cameras by PnP, each held at its own image centre;
  - **Phase 3:** all cameras, stage 4 of the same pipeline.
- **Each camera's start is its own:** its principal point starts at its own image centre (its Width and Height,
  `_get_cam_setting`).
- **The bounds are not (B11):** the pipeline bounds every camera's principal point around `self.image_size`'s centre,
  the first camera's:
  - ±0.1 px in stage 2;
  - ±50 px in stage 4, in Phase 1, and in Phase 3, where stages 1–3 are skipped.

  A camera of another size therefore starts outside its bounds, and scipy refuses ("Initial guess is outside of
  provided bounds"). That happens in Phase 1 when the camera is in the best pair, and in Phase 3 otherwise.
- **Nothing else in the fit uses the first camera's size:**
  - the residual functions take an image size but do not use it;
  - the PnP of Phase 2 uses each camera's own;
  - after the fit, `final_params[c]['img_size']` is each camera's own.
  - The results page, the error table and the 3D View read each camera's own size and its real id.
- **B12:** `calibrate_wand` builds `cam_id_map = {camera id: internal index}`. Every user reads it that way except
  `_parse_results`, which takes `cam_id_map[internal index]`. That works only while the ids are 0…N-1.

## Addendum: your choice, option 2 ("use 2.")

The fast mode stays and becomes repeatable.

**The change (B13):** `refine_circle_with_edges`, the fast mode's RANSAC circle fit, draws its samples from its own
generator with a fixed seed (`np.random.default_rng(FAST_RANSAC_SEED)`, a new module constant 0), in place of numpy's
global random state.
- **Repeatable:** every circle's draws are then the same, so an image's points depend only on the image and the
  settings: not on the run, the process, or whether Test Detect or Process All Frames ran it.
- **Leaves other code alone:** numpy's global state is no longer touched.
- **Who it affects:** only the fast mode (and the cylinder campaign's T13 scripts that call `detect_circles_robust`;
  their archived numbers came from unseeded draws).
- **What changes once:** its points, by about the 0.04 px two unseeded runs differed by in D2.
