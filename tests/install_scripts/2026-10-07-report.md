## 2. What was wrong (diagnoses D0–D4, read-only)

- **The installers could not install the package list.** `requirements.txt` lists pycine, which is not on
  conda-forge for any platform (D0). Every installer's `mamba install -c conda-forge --file requirements.txt` therefore
  stopped with `PackagesNotFoundError` (D1).
- **mamba was assumed:** `install_windows.bat`, `install_mac.command` and `update_openlpt.bat` called it
  unconditionally. Anaconda and Miniconda have only conda, as this PC does.
- **Windows got MKL:** conda-forge's solve picks MKL for BLAS on win-64 (D2). That is the set-up under which numpy's
  linear algebra crashed the interpreter in refract. With `libblas=*=*openblas` it picks refract's OpenBLAS build
  (D3).
- **QtWebEngine was in no list.** The camera calibration's Report tab needs `qt6-webengine` from conda-forge (win-64,
  linux-64 and osx-arm64; none for osx-64).
- **Python 3.10** in the scripts and the README; the code is developed and tested on 3.11.
- **`update_openlpt.bat`** hard-coded VS 2022 Community's `vcvarsall.bat`.
- **Mixed channels:** the environment came from the default channels, then the packages from conda-forge (D4: on this
  PC conda-forge comes first and works).
- **pyOpenLPT's `CLAUDE.md`** said `pip install -r requirements.txt`, which cannot work with conda-forge names.
