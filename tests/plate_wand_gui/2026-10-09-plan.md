# The GUI's flat-window (Pinhole+Refraction) wand calibration: the options of the real case — plan

9 October 2026. **Status: approved 9 Oct ("yes, go ahead") with D1 (b) "Radial k1" by default, D2 (a) per-window
values, D3 (a) the panel's values for the refit, D4 (a) fields; report `2026-10-09-report.md`.**

You asked: "Improve gui for refract+plate". Earlier the same day you asked whether the GUI's refract+plate calibration
runs the new algorithm. It does (`plate_wand.calibrate`, the same committed code), but the GUI cannot set what the real
case `cases/plate_20260727_T0` needed. Its delivered fit W4c (`calib_plate_wand_ref_centre`) was
`run_calibration.py --fit-k1 --channel --aim centre --start tests/states/t2_all.pkl`. The double check is in
`tests/vsc_correction_field/2026-10-09-report.md` §5.

**Goal:** the GUI can make the case's fits from the same inputs, and today's defaults stay as they are, except where you
choose otherwise (D1).

## 1. What the GUI lacks today (code facts)

- **No start from a saved fit.**
  - **What exists:** the GUI can only search, or "Refit from the last result" of the same session (`_plate_last`, in
    memory).
  - **Trap:** that refit uses the previous run's thickness and indices, not the panel's (`plate_wand_gui.run`,
    126-130).
  - **What the case did:** it kept the start's planes and applied the run's thickness and indices
    (`run_calibration.py:55-62`).
  - **No loader:** no library function rebuilds a start (cameras + rig) from a result folder. The pieces exist:
    `plate_wand_io.load_camfile` → `plate_model.from_cpp`, and every value is in `calibration_result.json`.
- **No constraints.** `Job` has no field for them, and `run` never passes `constraints` (channel, aim, distance).
- **Lens terms:** only k1. "Radial k1+k2" is refused, and `fit_lens` (pp, k2, tangential) cannot be set.
- **No hints.** `Job.hints` exists but the view never sets it.
- **One thickness and one index set for every window** (default 10 mm, 1.0 / 1.49 / 1.333). The case's walls are
  12.7 mm.
- **k1 off by default:** the distortion box starts at "None (0)".
- **The record:** `calibration_result.json` and the results page do not record the start's source, hints or
  constraints.
- **A small bug:** `gui.seconds` is always empty (the GUI reads `info["total_seconds"]`, which plate_wand never sets).

## 2. Changes (all in the wand tab's Pinhole+Refraction path; the pinhole and cylinder paths untouched)

- **F1 Windows table.** One row per window: thickness (mm) and the plate's index, filled from today's boxes.
  - Air and water stay single values.
  - The table follows `window_count_spin`.
  - Unedited, the Job is identical to today's.
- **F2 Start.** A "Start" choice:
  - **Search** (today's default);
  - **The last result of this session** (today's checkbox);
  - **A saved result folder:** a plate_wand result (camFile/ + calibration_result.json, written by the GUI or the case
    scripts), or a PINPLATE camFile folder.
    - **New loader** `plate_wand_io.load_start(folder, cam_ids, cam_to_window)` → (cameras, rig). It uses the JSON
      when present; otherwise the camFiles, grouped by the GUI's camera-window mapping.
    - **Matching:** cameras by id. A missing camera or a mismatched mapping is refused with a message.
  - **For every start,** the panel's thickness and indices are applied over the start's planes, as the case did.
- **F3 Constraints** (optional, off by default).
  - **The channel:** inside width per window (a column of the windows table), tolerance, and the two balls' radii.
  - **Aims:** rows of (cameras, wall, depth mm); held, or with a σ.
  - **Distances:** rows of (camera, mm).
  - Validated before the run, passed as `constraints`, and reported (`constraint_report`) in the message, the results
    page and the report.
- **F4 Lens terms.** Allow "Radial k1+k2" (fit_k1 + `fit_lens` k2), and add two checkboxes: "Fit the principal
  point" (pp) and "Tangential" (p1, p2).
- **F5 Hints** (only when searching).
  - **Choices:** None (default); "Windows face the cameras" (the case's photo hints: each window's normal along the
    camera's axis); "From a camFile folder" (each camera's window normal in its own frame, from an earlier PINPLATE
    calibration, as the case's `gui:calib_3`).
  - **The box's role:** it tilts the search toward a hint; the fit still decides.
- **F6 Record and show.**
  - `calibration_result.json`'s `gui` block and the results page list the start (and its folder), the hints, the lens
    terms and the constraints.
  - `gui.seconds` is fixed.
- **Precalibrate (stages 1-3)** keeps searching from scratch. It takes F1's windows and F5's hints but no start or
  constraints, since the library's start search takes none.

## 3. Decisions for you

- **D1 k1's default for Pinhole+Refraction.**
  - (a) **keep "None (0)"** (today);
  - (b) **"Radial k1"**: the real case needed it ("k1 must be fitted"). But the synthetic campaign (W3/W5) measured
    without it, and a pinhole-model run keeps its own default either way.
  - **Recommended: (b)**, with a note in the report when k1 is off.
- **D2 Per-window values.**
  - (a) **thickness and plate index per window** (F1);
  - (b) **keep one set for every window**, and only show the thickness more prominently.
  - **Recommended: (a).**
- **D3 The in-session refit.**
  - (a) **apply the panel's thickness and indices** over the last result's planes (as every start in F2);
  - (b) **keep today's behaviour** (the last result's values).
  - **Recommended: (a):** what you see is what runs.
- **D4 Constraints input.**
  - (a) **fields** in the panel (F3);
  - (b) **a JSON file** in the case's format;
  - (c) **both.**
  - **Recommended: (a).** Distances could wait if you never use them.
